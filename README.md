# Site de visite audio de l'église de Chêne-Arnoult
## Audio
Déposer dans le dossier `audio` les fichiers `01.mp3` à `31.mp3`.
## GitHub Pages
Créer un dépôt public, envoyer tous ces fichiers à sa racine, puis Settings > Pages > Deploy from a branch > main > /(root).
## QR codes
Attendre d'avoir choisi l'adresse publique définitive avant de les générer.
## Source
Les notices reprennent le document fourni. Cette version ne réalise pas de vérification historique externe des notices.
